# ClipNest

ClipNest 是一个为 Windows 10 打造的本地剪贴板历史工具。它常驻系统托盘，自动保存你复制过的文字、截图和图片；点击托盘图标或按下快捷键，就能从右下角唤出一个类似 macOS 上 Maccy 的轻量列表。

所有数据都只保存在本机，不需要登录，也不会上传云端。

## 已实现功能

### 剪贴板记录

- 自动记录文字、富文本和图片（PNG / JPG / BMP / 截图）
- 图片同时保存原图和轻量缩略图，列表滚动更流畅
- 重复内容自动去重，并把最近一次复制的内容移到顶部
- 支持最大条数限制、按天自动清理、已固定项目永久保留
- 单条文本最大 100 万字符，单张图片默认最大 30 MB
- 暂停记录功能：临时处理敏感内容时不会写入历史

### 托盘与窗口

- 常驻 Windows 右下角托盘，点击图标打开/收起面板
- 面板从托盘位置弹出，失焦自动收起
- 全局快捷键默认 `Alt + V`，可在设置中重新录制
- 开机启动（安装版可用）
- 单实例运行；重复启动只会唤起已有窗口
- 支持浅色 / 深色 / 跟随系统三种主题

### 列表交互

- 文字预览、图片缩略图、富文本标记、字符数、文件大小和相对时间
- 实时搜索，文字和图片属性都可以搜索
- 全部 / 文字 / 图片 / 已固定四种筛选
- 固定、取消固定、删除、图片大图预览
- 右键菜单：复制、以纯文本复制、固定、删除
- 键盘操作：
  - `↑` / `↓` 选择
  - `Home` / `End` 跳到首尾
  - `Enter` 复制
  - `Ctrl + F` 聚焦搜索
  - `Ctrl + P` 固定 / 取消固定
  - `Shift + Delete` 删除
  - `Esc` 清空搜索 / 返回 / 关闭
- 可选“选中后自动粘贴”：复制后模拟 `Ctrl + V` 粘贴到上一个窗口（实验性）

### 设置与隐私

- 快捷键录制与冲突检测
- 图片记录、富文本格式、自动粘贴开关
- 历史条数、保留天数设置
- 清空历史（二次确认）
- 直接打开数据目录
- 数据目录、图片目录、日志的占用空间统计
- 渲染进程启用 `contextIsolation` + sandbox，禁用 Node 集成
- 不包含任何网络请求、账号或遥测逻辑

## 使用

### 直接运行安装包

构建后的安装包位于：

```text
release/ClipNest-Setup-1.0.0-x64.exe
```

安装后从开始菜单或桌面启动 ClipNest。第一次启动会显示历史面板，之后默认静默驻留托盘。

> 当前安装包未使用商业代码签名证书。Windows SmartScreen 可能提示“未知发布者”，可选择“更多信息 → 仍要运行”。如果安全软件拦截，请将该文件加入信任。

也可以使用免安装版：

```text
release/ClipNest-Portable-1.0.0-x64.exe
```

### 使用快捷键

1. 在任意应用中复制内容。
2. 按 `Alt + V` 或点击托盘图标。
3. 用 `↑` / `↓` 选择，按 `Enter` 复制。
4. 粘贴到目标位置。

## 本地开发

环境要求：

- Node.js 22.12+（仓库内的 `.tools/node` 是本次开发用的便携版）
- Windows 10 22H2 或更新版本

```bash
npm install
npm run dev
```

构建前端资源：

```bash
npm run build
```

生成图标：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/generate-icons.ps1
```

打包：

```bash
npm run pack       # 生成 unpacked 目录，便于调试
npm run dist       # 生成 NSIS 安装包和 portable 单文件
```

开发模式下不建议把 `node_modules` 和 `release` 提交到版本库。

## 数据位置

默认数据目录：

```text
%APPDATA%\ClipNest
```

包含：

```text
history.json     剪贴板历史元数据和文字
settings.json    设置
images/          图片原图和缩略图
clipnest.log     运行日志（不记录剪贴板正文）
```

删除 `images` 目录或历史记录不会影响系统剪贴板本身。

## 技术结构

```text
electron/main.js     主进程：剪贴板监听、托盘、窗口、存储、IPC
electron/preload.js  安全的渲染进程桥接
src/main.jsx         React 界面
src/styles.css       视觉样式与主题
scripts/             图标生成
```

主进程通过 Windows `GetClipboardSequenceNumber`（Koffi FFI）判断剪贴板是否变化。没有变化时不会读取图片数据，因此空闲轮询开销很低；如果该能力不可用，会自动回退到内容指纹轮询。

## 已知限制

- “自动粘贴”通过 PowerShell 模拟 `Ctrl + V`，部分管理员权限窗口、远程桌面或输入法特殊场景可能失效。
- 目前不会识别或排除密码管理器等敏感窗口，建议在处理敏感内容前使用托盘里的“暂停记录”。
- 富文本通过 HTML 保存；部分应用只提供 RTF 时可能退化为纯文本。
- 图片格式会统一转成 PNG；复制的 GIF 会变成静态首帧。
- 暂不支持文件列表、OCR、云同步和多设备同步。
